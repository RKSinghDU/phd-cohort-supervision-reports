## Viewing the HTML Report

This is a **private** repository. Rendered HTML viewing requires one of:

### Option 1 — Clone & open locally (recommended for confidential review)

```bash
git clone https://github.com/RKSinghDU/phd-cohort-supervision-reports.git
cd phd-cohort-supervision-reports
open index.html   # macOS
start index.html  # Windows
xdg-open index.html  # Linux
```

### Option 2 — Direct download

From the [index.html page on GitHub](https://github.com/RKSinghDU/phd-cohort-supervision-reports/blob/main/index.html), click **Raw** then save the file locally and open in browser.

### Option 3 — Enable GitHub Pages (requires public repo OR GitHub Pro)

If you want a shareable URL like `https://rksinghdu.github.io/phd-cohort-supervision-reports/`:

1. Either make the repo public (⚠️ exposes student names) **or** ensure you're on GitHub Pro (Pages works on private repos for Pro+ accounts)
2. Go to **Settings → Pages**
3. Set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`
4. Save. The site will be live in ~1 minute.

## Data Sensitivity Note

⚠️ This repository contains **real student names and detailed academic assessments**. It is set to **private** by default. If you make it public to enable Pages hosting, the content becomes world-readable. Consider:

- Redacting student names to initials (e.g., R.C., K., S.D.) before going public
- Keeping it private and sharing via clone/download instead
- Upgrading to GitHub Pro for private Pages hosting
